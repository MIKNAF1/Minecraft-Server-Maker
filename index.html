Port forwarding

The manual router method. Free, but the most technical.

Step 1 — find your computer's local address
Press the Windows key + R, type cmd, press Enter. In the black window type ipconfig and press Enter. Look for IPv4 Address — it looks like 192.168.x.x. That number is your server address on your Wi-Fi.
  • Start your server (open Start.bat) and leave it running.
  • Find your IPv4 address using the button above.
  • Make sure your friends are on the same Wi-Fi as you.
  • In Minecraft they click Multiplayer → Add Server.
  • They type your address, e.g. 192.168.1.20:25565, and join.
playit.gg gives your server a public address for free — no router changes, friends can be anywhere. Keep the playit app open while you play.
  • Start your server (Start.bat) and leave it running.
  • Download playit.gg and install it. Open playit.gg →
  • Open the playit app and sign in (free account).
  • Add a Minecraft Java tunnel — it points to 127.0.0.1:25565 by default, which is correct.
  • playit shows you an address like yourname.playit.gg. That is your server address.
  • Share that address. Friends use Multiplayer → Add Server and paste it in.
Heads up: port forwarding opens your home network to the internet. It works well but is the most technical option, and steps differ per router. If it feels like too much, use the "Anywhere (online)" option instead.
  • Find your local IPv4 address (ipconfig → IPv4, like 192.168.x.x).
  • Open your router page in a browser: usually 192.168.0.1 or 192.168.1.1.
  • Log in (the password is often on a sticker on the router).
  • Find Port Forwarding and add a rule: port 25565, type TCP, pointing to your local IPv4.
  • If Windows asks, allow Java through the firewall.
  • Find your public IP (search "what is my ip"). That is what friends use, e.g. 1.2.3.4:25565.
That's everything. Your friends should be able to join now. If a friend can't connect, double-check the server is running and they typed the address exactly, port included.

Optional: get a nicer address

Instead of the long playit address, friends can use something short. Pick how fancy you want to get — the first one is the easiest by far.

  1. 1In playit.gg, open your tunnel and click the Change domain button (top right).
  2. 2Pick any free name it offers you (like something.joinmc.link) and save.
  3. 3That new name is your address — share it with friends. Done.
